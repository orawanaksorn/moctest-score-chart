Exam Score Chart — Developer Guide

วิธีสร้าง Exam Score Comparison Chart

เอกสารนี้อธิบายขั้นตอนและโค้ดทั้งหมดที่ใช้สร้างกราฟเปรียบเทียบคะแนนสอบ ที่มีแท่ง ประเทศ กว้าง (สีเทา) ทับซ้อนกับแท่ง โรงเรียน แคบ (สีน้ำเงิน) และ ดาวทอง แสดงคะแนนตัวเอง รวมถึงกราฟจำนวนผู้สอบแยกต่างหาก และ UI จัดการข้อมูลแบบ inline

4. แนวคิดกราฟ Overlay

ปัญหาหลักของกราฟชนิดนี้คือต้องการให้ 3 element (แท่งประเทศ, แท่งรร., ดาว) อยู่ที่ แกน x เดียวกัน ซึ่ง Recharts ปกติจะจัดแท่งในกลุ่มเดียวกันแบบ side-by-side

วิธีแก้ — Single Bar + Custom Shape

1

ใช้ Bar เดียว (dataKey="national")

Recharts คำนวณ y, height ให้สำหรับคะแนนประเทศ รวมถึงกำหนด x, width ของ slot

2

Custom shape function ได้รับ props จาก Recharts

x, y, width, height, payload — ทุก element ใช้ x+width/2 เป็น cx เดียวกัน

3

คำนวณ y ของ School และ Star จาก Scale ของ National

baselineY = y + height (pixel ที่ value = 0)
pixPerUnit = height / national
schoolY = baselineY − school × pixPerUnit

4

วาด 3 element ใน <g> เดียว

ลำดับใน SVG: national rect (ล่างสุด) → school rect → star polygon (บนสุด)

// สูตรคำนวณ y position ทั้ง 3 element
function OverlayBar(props: any) {
  const { x = 0, width = 0, y = 0, height = 0, payload } = props;

  const cx        = x + width / 2;          // center x — ใช้ร่วมกันทุก element
  const baselineY = y + height;             // y ของ value = 0 (แกน x)
  const pixPerUnit = payload.national > 0   // pixel ต่อ 1 หน่วยคะแนน
    ? height / payload.national
    : 0;

  const schoolH = payload.school * pixPerUnit;
  const schoolY = baselineY - schoolH;

  const meY = baselineY - payload.me * pixPerUnit;   // y ของดาว

  return (
    <g>
      {/* แท่งประเทศ — กว้าง 52px */}
      <rect x={cx - 26} y={y} width={52} height={height} ... />
      {/* แท่งรร. — แคบ 28px ทับอยู่ข้างใน */}
      <rect x={cx - 14} y={schoolY} width={28} height={schoolH} ... />
      {/* ดาว — อยู่ที่ระดับคะแนน me */}
      <StarGlyph cx={cx} cy={meY} />
    </g>
  );
}

5. Score Chart — Code ทีละส่วน

5.1 StarGlyph — ดาว 5 แฉก

วาดด้วย SVG <polygon> คำนวณจุดยอด 10 จุด (สลับ outer/inner radius):

function starPolygon(cx: number, cy: number, r: number): string {
  return Array.from({ length: 10 }, (_, i) => {
    const angle  = (i * Math.PI) / 5 - Math.PI / 2;  // เริ่มจากยอดบน
    const radius = i % 2 === 0 ? r : r * 0.42;        // สลับ outer/inner
    return `${cx + radius * Math.cos(angle)},${cy + radius * Math.sin(angle)}`;
  }).join(' ');
}

function StarGlyph({ cx, cy }: { cx: number; cy: number }) {
  return (
    <g style={{ filter: 'drop-shadow(0 0 7px rgba(247,201,72,0.95))' }}>
      <polygon
        points={starPolygon(cx, cy, 13)}  // r=13 px
        fill="#f7c948"
        stroke="#fffbe6"
        strokeWidth={1.5}
      />
    </g>
  );
}

5.2 OverlayBar — หัวใจของกราฟ

function OverlayBar(props: any) {
  const { payload, x = 0, width = 0, y = 0, height = 0 } = props;
  if (!payload) return null;

  const cx         = x + width / 2;
  const baselineY  = y + height;
  const pixPerUnit = payload.national > 0 ? height / payload.national : 0;

  const nationalH = Math.max(0, height);
  const schoolH   = Math.max(0, Math.round(payload.school * pixPerUnit));
  const schoolY   = baselineY - schoolH;
  const meY       = baselineY - Math.max(0, payload.me * pixPerUnit);

  return (
    <g>
      {/* ① ประเทศ — กว้าง สีเทา วาดก่อน (อยู่ล่าง) */}
      <rect
        x={cx - 26} y={y}
        width={52} height={nationalH}
        fill="rgba(148,163,184,0.38)"
        stroke="rgba(100,116,139,0.22)" strokeWidth={1}
        rx={7}
      />
      {/* ② โรงเรียน — แคบ สีน้ำเงิน วาดทีหลัง (อยู่หน้า) */}
      <rect
        x={cx - 14} y={schoolY}
        width={28} height={schoolH}
        fill="#2f6fed" rx={5}
      />
      {/* ③ ดาว — คะแนนตัวเอง */}
      <StarGlyph cx={cx} cy={meY} />
    </g>
  );
}

5.3 Custom Tooltip

เพราะใช้ Bar เดียว payload จาก recharts มีแค่ national — ให้อ่านข้อมูลครบจาก payload[0].payload (row เดิม): 

function ScoreTooltip({ active, label, payload }: {
  active?: boolean;
  label?: string;
  payload?: Array<{ payload?: Score }>;
}) {
  if (!active || !label || !payload?.length) return null;
  const row = payload[0]?.payload;          // ← row ต้นฉบับ มีครบทุก field
  if (!row) return null;
  return (
    <div className="scoreTooltip">
      <p><strong>{label}</strong></p>
      <p>ค่าเฉลี่ยประเทศ: <strong>{row.national}</strong></p>
      <p>ค่าเฉลี่ยโรงเรียน: <strong>{row.school}</strong></p>
      <p>คะแนนของฉัน: <strong>{row.me}</strong></p>
    </div>
  );
}

5.4 ComposedChart ที่สมบูรณ์

export function ScoreChart({ data, title = 'เปรียบเทียบคะแนนสอบ' }: ScoreChartProps) {
  // คำนวณ Y max แบบ dynamic — ขยายถ้าคะแนนเกิน 100
  const allValues = data.flatMap((d) => [d.national, d.school, d.me]);
  const rawMax    = allValues.length ? Math.max(...allValues) : 100;
  const yMax      = Math.max(100, Math.ceil(rawMax / 10) * 10 + 5);

  const manySubjects  = data.length > 5;
  const chartMinWidth = Math.max(480, data.length * 110);  // ขยาย + scroll

  return (
    <div style={{ minWidth: chartMinWidth, height: 420 }}>
      <ResponsiveContainer width="100%" height="100%">
        <ComposedChart
          data={data}
          margin={{ top: 30, right: 24, left: 0, bottom: manySubjects ? 64 : 16 }}
        >
          <CartesianGrid vertical={false} stroke="rgba(148,163,184,0.18)" />

          <XAxis
            dataKey="subject"
            axisLine={false} tickLine={false}
            tick={{ fill: '#475569', fontSize: 13, fontWeight: 700 }}
            angle={manySubjects ? -38 : 0}      // เอียง label ถ้าวิชาเยอะ
            textAnchor={manySubjects ? 'end' : 'middle'}
            height={manySubjects ? 80 : 40}
          />

          <YAxis
            domain={[0, yMax]}                   // dynamic domain
            axisLine={false} tickLine={false}
            tick={{ fill: '#64748b', fontSize: 12 }}
            width={36}
          />

          <Tooltip content={<ScoreTooltip />} cursor={{ fill: 'rgba(15,23,42,0.04)' }} />

          {/* Bar เดียวที่วาดทั้ง 3 element */}
          <Bar
            dataKey="national"
            barSize={56}
            shape={(p: any) => <OverlayBar {...p} />}
            isAnimationActive={false}
          />
        </ComposedChart>
      </ResponsiveContainer>
    </div>
  );
}
✅

isAnimationActive={false} จำเป็น — animation ใน recharts ทำให้ custom shape flicker ระหว่าง transition

6. Count Chart — กราฟจำนวนผู้สอบ

ใช้ BarChart (ไม่ใช่ ComposedChart) เพราะมี series เดียว ง่ายกว่า:

function CountBar({ x = 0, y = 0, width = 0, height = 0 }: any) {
  if (height <= 0) return null;
  const r = Math.min(7, width / 3);       // rounded top corners
  return <rect x={x} y={y} width={width} height={height} fill="#0ea5e9" rx={r} />;
}

export function CountChart({ data }: { data: Score[] }) {
  const maxCount = data.length ? Math.max(...data.map((d) => d.count)) : 0;
  const yMax     = Math.ceil(maxCount / 100) * 100 + 100;

  return (
    <ResponsiveContainer width="100%" height={300}>
      <BarChart data={data} margin={{ top: 28, right: 24, left: 0, bottom: 16 }}>
        <CartesianGrid vertical={false} stroke="rgba(148,163,184,0.18)" />
        <XAxis dataKey="subject" axisLine={false} tickLine={false}
               tick={{ fill: '#475569', fontSize: 13, fontWeight: 700 }} />
        <YAxis domain={[0, yMax]} axisLine={false} tickLine={false}
               tick={{ fill: '#64748b', fontSize: 12 }} width={52}
               tickFormatter={(v: number) => v.toLocaleString()} />
        <Tooltip cursor={{ fill: 'rgba(15,23,42,0.04)' }} />
        <Bar dataKey="count" barSize={44} shape={(p: any) => <CountBar {...p} />}
             isAnimationActive={false}>
          {/* Label ตัวเลขบนแท่ง */}
          <LabelList
            dataKey="count"
            position="top"
            formatter={(v: unknown) =>
              typeof v === 'number' ? v.toLocaleString() : String(v ?? '')}
            style={{ fill: '#0f172a', fontSize: 11, fontWeight: 700 }}
          />
        </Bar>
      </BarChart>
    </ResponsiveContainer>
  );
}

7. State Management (Page Level)

State ทั้งหมดอยู่ใน page.tsx (Client Component) — ส่งลงให้ chart ผ่าน props และรับ callback กลับมา: 

'use client';
import { useState } from 'react';

export default function Page() {
  const [scores, setScores] = useState<Score[]>(DEFAULT_SCORES);

  // เพิ่มวิชา
  function addSubject(newScore: Score) {
    setScores((prev) => [...prev, newScore]);
  }

  // ลบวิชา
  function removeSubject(subject: string) {
    setScores((prev) => prev.filter((s) => s.subject !== subject));
  }

  // แก้ไขวิชา (replace by subject key)
  function editSubject(oldSubject: string, updated: Score) {
    setScores((prev) => prev.map((s) => s.subject === oldSubject ? updated : s));
  }

  return (
    <>
      <ScoreChart data={scores} onRemove={removeSubject} onEdit={editSubject} />
      <CountChart data={scores} />
      {/* form เพิ่มวิชา */}
    </>
  );
}

8. Inline Edit ในตาราง

Edit state เก็บใน ScoreChart เอง (local state) แล้ว call onEdit callback เมื่อบันทึก: 

// State ใน ScoreChart component
const [editingKey, setEditingKey] = useState<string | null>(null);
const [editForm,   setEditForm]   = useState<EditForm>({ subject:'', national:'', ... });

// เริ่ม edit
function startEdit(item: Score) {
  setEditingKey(item.subject);
  setEditForm({ subject: item.subject, national: String(item.national), ... });
}

// บันทึก → ส่งค่าใหม่ขึ้นไปหา parent
function saveEdit() {
  if (!editingKey || !onEdit) return;
  const subject = editForm.subject.trim();

  // Validate
  if (!subject) { setEditError('ชื่อวิชาห้ามว่าง'); return; }
  if (subject !== editingKey && data.some((d) => d.subject === subject)) {
    setEditError(`วิชา "${subject}" มีอยู่แล้ว`); return;
  }

  onEdit(editingKey, {
    subject,
    national: Number(editForm.national) || 0,
    school:   Number(editForm.school)   || 0,
    me:       Number(editForm.me)       || 0,
    count:    Number(editForm.count)    || 0,
  });
  setEditingKey(null);
}

ใน JSX ตาราง ตรวจสอบ isEditing เพื่อ switch ระหว่าง text และ input:

data.map((item) => {
  const isEditing = editingKey === item.subject;
  return (
    <tr key={item.subject}>
      {isEditing ? (
        // Mode แก้ไข — แสดง input fields
        <>
          <td><input value={editForm.subject} onChange={setEF('subject')} /></td>

        <>

          </td>

})

9. นำไป Plug ใน Project อื่น
